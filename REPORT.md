# Отчёт: Smart Campus AI

## 1. Цель
Создать учебный прототип информационной системы Smart Campus: веб-панель для контроля помещений, IoT-устройств, энергопотребления и инцидентов с модулем обнаружения аномалий.

## 2. Архитектура
Статический многостраничный сайт без backend. Слои: `data.js` (исходные данные) → `storage.js` (localStorage, симуляция опроса датчиков) → `ai.js` (аналитика) → `layout.js` (общий каркас) → скрипты страниц. Данные хранятся в localStorage в виде JSON (`sc_rooms`, `sc_devices`, `sc_incidents`, `sc_settings`, `sc_user`, `theme`).

## 3. Реализовано
Login с ролями · Dashboard (5 KPI, 3 графика Chart.js, уведомления) · Rooms (12, поиск, фильтры) · Devices (28, поиск, фильтры) · Incidents (CRUD, приоритет, ответственный, комментарий) · Analytics (аномалии, z-score, рекомендации, 2 графика) · Settings (тема, сброс) · Notifications (колокольчик) · адаптивность 1920/1366/768/390 px · тёмная/светлая тема.

## 4. AI Analytics
Пороги по температуре, CO₂ и энергии + z-score по 10 последним показаниям (z > 2). Для каждой аномалии выводятся причина, уровень риска и рекомендация.

## 7. Вывод
Получен работающий прототип панели управления кампусом на чистом HTML/CSS/JS. Показаны CRUD, работа с localStorage, визуализация данных и прозрачный статистический подход к поиску аномалий. Развитие: настоящий backend, реальные датчики, серверный вызов AI API для отчётов.

## Контрольные вопросы (кратко)
1. Smart Campus: кампус с датчиками и системами, управляемыми по данным.
2. IoT: температура, CO₂, освещённость, электроэнергия, доступ, состояние оборудования.
3. CRUD: Create, Read, Update, Delete.
4. localStorage: хранение данных в браузере между сеансами.
5. JSON: текстовый формат обмена данными.
6. Chart.js: библиотека построения графиков на canvas.
7. Аномалия: значение, сильно отклоняющееся от нормы или истории.
8. Z-score: (x − среднее) / σ; большое значение означает сильное отклонение.
9. Правила дают фиксированный ответ по условиям; генеративный AI создаёт текст моделью.
10. Ключ в браузерном JS виден любому пользователю.
11. Git: система контроля версий.
12. GitHub Pages: бесплатный хостинг статических сайтов из репозитория.
